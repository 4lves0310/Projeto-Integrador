# IFSC Adventures

IFSC Adventures é um jogo digital 2D desenvolvido como projeto integrador
do curso Técnico em Informática do IFSC – Câmpus Gaspar.

O jogo foi desenvolvido com perspectiva Top-Down e tem como inspiração
jogos de exploração em 2D. O jogador poderá explorar o ambiente,
interagir com NPCs e objetos e realizar missões ao longo da jornada.

## Objetivo

Desenvolver um jogo digital de exploração ambientado em um campus
inspirado no IFSC, proporcionando uma experiência de entretenimento
baseada no ambiente escolar.

## Ferramentas

- Unity
- C#
- Visual Studio Code
- Git e GitHub
